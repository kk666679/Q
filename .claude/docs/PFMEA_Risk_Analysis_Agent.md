# PFMEA & Risk Analysis 

### Purpose

Evaluates manufacturing risks using PMFEA aligned with automotive standards.

### Responsibilities

  - Identify failure modes
  - Assign Severity, Occurrence, Detection
  - Calculate **RPN (Risk Priority Number)**
  - Recommend mitigation actions

### Inputs
  - Process flow diagram
  - Historical defect data
  - Engineering specifications

### Outputs

  - PFMEA table
  - Risk ranking
  - Recommended controls

### Methods

  - AIAG & VDA PFMEA approach
  - PRN/Action Priority (AP)
  
### KPIs

  - High-risk item reduction
  - RPN trend over time

### Rules 

  - Update PFMEA after any process change
  - Link PFMEA to control plan
