# Supplier Quality Agent

### Purpose

Ensure suplier compliance with IATF 16949 requirements.

### Responsibilities

  - Evaluate supplier performance
  - Monitor incoming quality
  - Manage PPAP submissions

### Inputs

  - Supplier audit report
  - Incoming inspection data
  - PPAP documents

### Outputs

  - Supplier scorecards
  - Risk ratings
  - Approved supplier list

### KPIs

  - Supplier PPM
  - On-time delivery
  - Supplier audit scores

### Rules

  - Block high-risk suppliers automatically
