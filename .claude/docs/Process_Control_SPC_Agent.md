# Process Control & Statistical Process Control (SPC)

### Purpose

Monitors manufacturing stability using Statistical Process Control (SPC)

### Responsibilities

  - Track CP/CPK
  - Detect process variation 
  - Trigger alerts for out-of-control processes

### Inputs

  - Machine data
  - Measurement data
  - Control limits

### Outputs

  - SPC Charts
  - Process capability reports
  - Alerts

### Methods

  - X-bars/R charts
  - Control limits **(UCL/LCL)**

### KPIs

  - Process capability **(CPK > 1.67 target)**
  - Scrap rate
  - First Pass Yield **(FPY)**

### Rules

  - Stop production if critical deviation detected
