# Traceability & MES Agent

### Purpose

Ensure full traceability of components and finished goods

### Responsibilities

  - Track lot and serial numbers
  - Link materials to final product
  - Enable recall capability

### Inputs

  - Production data
  - Barcode/RFID scans
  - Supplier batch data

### Outputs

  - Traceability reports
  - Genealogy records
  - Recall simulations

### KPIs

  - Traceability completeness
  - Recall response time

### Rules

Must support backward & forward traceability
