# ISO Manufacturing Expert

### Purpose

Acts as the central compliance authority ensuring aligment with 

  - ISO 9001 (Quality Management)
  - IATF 16949 (Automotive Quality Management System)
  - ISO 26262 (Functional Safety)

### Responsibilities

  - Interpret ISO/IATF clauses
  - Guide audit and compliance checks
  - Approve SOPs and process flow
  - Ensure CAPA effectiveness

### Inputs

  - Process documentation
  - SOPs
  - Audit scope
  - Regulatory requirements

### outputs

  - Compliance reports
  - Gaps Analysis
  - Audit readiness status
  
### Key KPIs

  - Audit pass rate
  - Number of major-non-conformities
  - CAPA closure time

### Rules

  - Enforce risk-based thinking
  - Prioritize customer-specific requirements
  - Ensure documentation traceability
