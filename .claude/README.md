# Claude System Index — MyQMS AI Ecosystem
## 📋 System Overview
**MyQMS** is an AI-powered Quality Management System built for Malaysian standards and regulatory compliance. It combines audit planning, risk assessment, document control, CAPA management, and ISO-aligned workflows with Claude-enabled reasoning, domain knowledge, and multi-agent orchestration.

This Claude ecosystem indexes the AI agents, skills, knowledge bases, and workflow tools that support the platform's quality, compliance, and operational excellence capabilities.

### 🏗️ Architecture Components
| Component | Purpose | Location |
|-----------|---------|----------|
| **Agents** | Specialized AI assistants for quality, compliance, audit, and CAPA workflows | `agents/` |
| **Skills** | Domain-specific capabilities and reasoning templates for Malaysian standards | `skills/` |
| **Knowledge Base** | Structured QMS, ISO, and regulatory compliance reference content | `knowledge-base/` |
| **Tools** | Reusable AI utilities for audit, risk, document, and compliance tasks | `agents/scripts/tools/` |
| **Workflows** | Orchestrated processes for audits, CAPA, and compliance monitoring | `workflows/` |
